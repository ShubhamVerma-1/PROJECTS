# Data Jobs Dashboards | Power BI Practice Project

An interactive Power BI dashboard project built to explore the **data jobs market** across roles, salary levels, hiring trends, locations, job types, and application stages. This project was created as part of my Power BI practice while preparing for **Data Analyst roles**.

## Project Summary

This dashboard brings together multiple views of the data jobs landscape in one Power BI file. It is designed to help users quickly understand:

- which data roles are most common,
- which roles pay the most,
- how salary varies by country and job title,
- where jobs are concentrated globally,
- how job postings changed over time,
- what percentage of jobs mention a degree or remote work,
- how applicants move through the hiring funnel.

## Key Highlights

- **Single PBIX file** containing **10 dashboards/pages**
- Built with **Power BI visuals**, maps, charts, cards, tables, and slicers
- Includes **salary analysis**, **job trend analysis**, **location analysis**, and **application funnel analysis**
- Helps practice real dashboard design, data storytelling, and business insight generation

## What This Project Shows

This project focuses on the most important questions a candidate or recruiter may ask about the data jobs market:

- What are the top data-related job titles?
- Which roles offer the highest salary?
- How do yearly and hourly salaries compare?
- Which countries have the most postings?
- How many jobs mention degree requirements?
- How many jobs allow work from home?
- How does the application process move from views to hires?

## Insights You Can Explore

- **Data Engineer** and **Data Analyst** roles appear frequently.
- **Senior-level roles** generally offer higher salaries.
- **Work-from-home** and **degree requirement** patterns can be compared across job titles.
- Job postings vary by **country**, **quarter**, and **job type**.
- Salary and hiring trends can be analyzed through charts, maps, cards, and tables.

## How to Use

1. Download or clone the repository.
2. Open the `.pbix` file in **Power BI Desktop**.
3. Explore the pages using the slicers and navigation buttons.
4. Review the screenshots in this README to get a quick overview of the report.

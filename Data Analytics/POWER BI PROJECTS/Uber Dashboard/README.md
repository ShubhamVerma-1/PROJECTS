# Uber Auto Dashboard | Power BI Project

An interactive **Power BI dashboard** built to analyze ride-hailing performance for **Uber Auto**. This project focuses on operational KPIs, ride completion trends, revenue patterns, distance metrics, customer and driver ratings, and location insights.

## Project Overview

This dashboard was created as a Power BI project to explore how a ride-sharing business can be monitored through a single, easy-to-use report. It provides a clear view of:

- total completed rides and booking status,
- revenue by vehicle type and time period,
- monthly booking trends,
- pickup and drop location performance,
- average customer and driver ratings,
- total and average trip distance,
- ride completion funnel.

## Dashboard Highlights

- **23K** completed rides
- **14K** lost bookings
- **13M** revenue
- **625.62K** total distance
- **24.62** average distance
- Monthly and quarterly booking analysis
- Revenue comparison across vehicle types
- Top pickup and drop locations
- Customer rating and driver rating insights
- Ride status breakdown: completed, cancelled, incomplete

## What This Dashboard Helps Answer

- How many bookings were completed?
- How much revenue was generated?
- Which vehicle type contributes the most revenue?
- Which months had stronger or weaker performance?
- Which locations had the most pickups and drops?
- How do customer and driver ratings compare?
- What is the share of completed, cancelled, and incomplete rides?

## Dashboard Sections

- KPI summary cards
- Monthly booking trend chart

## Key Insights

- Completed bookings are much higher than incomplete rides, which shows strong operational activity.
- Revenue is concentrated more heavily in certain vehicle categories, especially the higher-volume ones.
- Booking trends change across months, making time-based analysis important.
- Pickup and drop locations can be used to understand route demand.
- Ratings help evaluate service quality from both customer and driver perspectives.

## How to Use

1. Open the `.pbix` file in **Power BI Desktop**.
2. Explore the KPI cards at the top for a quick summary.
3. Use the charts and toggles to analyze bookings, revenue, and distance.
4. Review ratings and location insights to understand service performance.
